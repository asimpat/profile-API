This project is a simple Django REST API built using Django and Django REST Framework (DRF).
It includes an endpoint that returns user information, a current timestamp, and a random cat fact fetched from an external API.

Setup Instructions
Clone the Repository
Navigate into the Project Directory
Create and Activate a Virtual Environment
Install Dependencies
Environment Variables


Running the Project Locally
Apply database migrations:
python manage.py migrate
Start the development server:
python manage.py runserver
Visit the API endpoint in your browser:
http://127.0.0.1:8000/me/

API Documentation
Swagger UI: http://127.0.0.1:8000/api/schema/swagger-ui/
